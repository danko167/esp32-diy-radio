# Fonts

Source fonts for the LVGL fonts in `src/ui/fonts/`. Regenerate with
`tools/gen_fonts.sh` (needs Node.js; uses `npx lv_font_conv`).

| File | Source | License |
|---|---|---|
| `Montserrat-Medium.ttf` | [Montserrat](https://github.com/JulietaUla/Montserrat), as bundled with LVGL | SIL OFL 1.1, `licenses/Montserrat-OFL.txt` |
| `FontAwesome5-Solid+Brands+Regular.woff` | [Font Awesome 5 Free](https://fontawesome.com), as bundled with LVGL | `licenses/FontAwesome5-LICENSE.txt` |
| `weathericons-regular-webfont.ttf` | [Weather Icons](https://github.com/erikflowers/weather-icons) by Erik Flowers | SIL OFL 1.1 |
| `DSEG7Classic-Bold.ttf` | [DSEG](https://github.com/keshikan/DSEG) v0.46 by keshikan, 7-segment digits | SIL OFL 1.1, `licenses/DSEG-OFL.txt` |
